# Ateliê Angela Crespo

Landing page estática para Firebase Hosting.

## Publicar no Firebase

1. Execute `firebase login --reauth` e autentique sua conta Google.
2. Execute `firebase projects:list` e escolha o projeto Firebase correto.
3. Associe o projeto com `firebase use --add`.
4. Publique com `firebase deploy --only hosting`.

As fotos do painel administrativo ficam salvas no navegador por `localStorage`.
